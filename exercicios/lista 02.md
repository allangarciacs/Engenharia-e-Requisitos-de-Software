# Lista de Exercícios II - Softwares / Engenharia de Software

---

## 1) Tente desenvolver um conjunto de ações para a atividade de comunicação. Selecione uma ação e defina um conjunto de tarefas para ela.

### Conjunto de ações: 
- **Levantamento de requisitos**
- **Reuniões de alinhamento**
- **Documentação de requisitos**
- **Validação com o cliente**

### Ação Levantamento de requisitos:
1 - Identificar stakeholders
2 - Marcar reuniões/entrevistas
3 - Fazer perguntas sobre necessidades do sistema
4 - Registrar requisitos
5 - Revisar com o cliente

## 2) Durante a comunicação, um problema comum ocorre ao encontrarmos dois envolvidos com ideias conflitantes sobre como o software deve ser. Isto é, há requisitos mutuamente conflitantes.
Desenvolva um padrão de processo que trate desse problema e sugira uma abordagem eficaz para resolvê-lo.
